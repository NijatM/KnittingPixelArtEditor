CELL

03 · START
Style
Every style is rendered from your photo. Pick one to start from; your edits will stay on their own layer.
PARAMETERS
Line weight thickens or thins the model's lines (style E). Cleanup removes lone cells that disagree with almost all of their neighbours; drawn features are protected. Style E downloads a 15 MB line model once, then runs on this device.
04 · START
Regions
Each region gets its own cut, so any face stays readable.
SKIN
HAIR
CLOTHES
0 keeps a region open (paper), 1 fills it with ink, 0.50 is each style's own balance. Skin is normalised first, so the slider means the same on every skin tone.
05 · START
Features
Drawn from the face points on top of the style.
GLASSES
—
When glasses are detected, the eyes are still redrawn and the frames are drawn as a thin outline around them.
06 · START
Background
Pattern fills the background with evenly spaced dots; photo keeps the real background, drawn in the same style. Density sets how much of it is ink. The outline is an ink line against white and a one-cell paper gap against everything else.
07 · EDIT
Draw

10 · MAKE
Export
One pixel per stitch.
FILE
SESSION
Saved in this browser. Only the last project is kept.
PNG and BMP: one pixel per stitch in exactly your two colours. BMP bit depth is your choice: 1, 4 or 8-bit store the colours as a palette, 24-bit stores plain RGB; depths too small for the palette are disabled. SVG merges each row's runs into paths, with cells drawn at the cell aspect. The project (photo, settings, edits) stays in this browser until you forget it or load another photo.
