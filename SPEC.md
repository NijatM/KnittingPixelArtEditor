# KnittingPixelArtEditor — v1 Spec

Agreed in planning session 2026-10-09. Evidence for every choice is in `RESEARCH.md` and `research/`. UI design: `design/DESIGN.md` + `design/mockup.html`. Session summary: `HANDOFF.md`.

**Goal:** a free, public, browser-only editor that turns a portrait photo into a *cohesive, appealing* 2-color pixel portrait (later knitted), then lets the person refine it by hand.

## Product decisions

| Area | Decision |
|---|---|
| Users | Anyone, public; one person per session; no accounts, no backend |
| Privacy | Photos never leave the device; everything runs client-side |
| Knitting | Deferred. Keep a **cell aspect-ratio** setting (default 1:1) for future gauge |
| Colors | Palette of indexed colors; v1 = **any 2 colors**, default pure black `#000000` / white `#ffffff` (was screen-tinted #0b0b0b / #f4f4f4 until 2026-10-14; saved projects with that pair move to pure) |
| Input | File picker, drag & drop, paste from clipboard. **Pixel images** (added 2026-10-14, `src/pixelart.ts`): a file with 2–16 flat colours (alpha < 128 = paper) whose colour changes sit on a cell grid opens as it is — no detection, no styles: one cell per pixel when it fits the editor (≤ 250 × 300; an exact enlargement shared by both axes, e.g. 100 px of a 50 × 50, is undone), otherwise whole-block or uneven enlargements are found from where the colours change and checked by redrawing (≤ 1 % off); more than two colours split into ink / paper by lightness (Otsu), each side's most used colour becomes the palette. The image is the frozen base (live off), the photo steps are dimmed, it autosaves like a photo project. JPEGs of pixel art open as photos (compression noise) |
| Framing | Auto-frame like the team's portraits (2026-10-14): at least 1.9 face widths across, wider when the hair is — the head box (hair + face from the hair's top to below the chin, from the segmentation) fills 90 % of the width — and the top of the hair 6 % below the frame's top edge; + tight↔wide slider + free drag/resize crop; pixels outside the photo = background; the frame tightens (≤ 25 %) so it ends at the photo's bottom edge instead of above a blank band |
| Frame shape | Quick ratios 1:1, 4:5, 3:4, 2:3 + free W×H |
| Size | Default **50×50** (1:1, the team's knitted portraits); quick widths 25 / 50 / 72 / 80 / 96 / 128 = the sizes the clean avatar's art exists at (2026-10-16); free entry for the photo styles — while the clean avatar is selected the grid snaps to those six, square |
| Background | Per portrait: white / black / pattern (Bayer dots, density slider) / photo (the real background drawn in the style, flat walls stay paper); "outline the person" = ink line against white, 1-cell paper gap against the others |
| Start | **Gallery grid**: every preset renders a thumbnail at the chosen size; click one to start. Default style: clean avatar |
| Presets | A **Clean avatar** (2026-10-16: put together from the team's 40 characters, below) · B **Image-driven avatar** (the traced avatar of 2026-10-14, "prelim avatar") · C Region poster · D Line portrait · E 4-tone patterns · F Atkinson tonal · G ML lines (Informative Drawings, `opensketch_style`). Letters follow the gallery order; code ids are `clean` · `avatar` · `poster` · `line` · `tone` · `tonal` · `ml` (saved projects with the old letters are mapped; `avatar` stays the image-driven one) |
| Clean avatar | Library: the 40 approved characters × 6 sizes, cut into **parts** by `scripts/build-avatar-library.py` (source folder stays local; output `public/avatars/`): hair with its head, ears, neck, shoulders (+ a beard or chin goatee drawn into the jaw, which stays with its hair) · eyes · brows · nose · mouth · glasses · facial hair (moustache, goatee, or a beard taken whole). **Custom** (default): the hair closest to the photo's (top, width at the eyes, volume, length beside the jaw, hairline, left–right balance, in eye distances, from the segmentation) with that character's own face, swapping in glasses (shape: round / square, lens aspect), facial hair (none / moustache / goatee / beard), closed eyes or a grin when the photo shows them; every part changeable in 08 Parts — rows hair + head, eyes, brows, nose, mouth, glasses, facial hair (options = one per look-alike group that fits this face). Auto face parts come from the closest character whatever hair is picked, so changing one part never changes the others; a part that doesn't fit the picked face becomes the most similar one that does (same kind, closest size). **Prebuilt**: one character exactly as drawn; auto = the closest; changing a part makes it custom from that character. Works without a photo (prebuilt, "start from a character"). Parts are placed at the head's own eyes (mirror-wise per side), nose and mouth; glasses bridges and arms refitted; brows kept off hair and frames; a paper cell around the mouth in facial hair |
| Feature extraction | MediaPipe Face Landmarker + Selfie Multiclass segmentation; on detection failure, filter-only presets |
| Skin | Region-normalized by default + **skin density** slider (all region sliders: 0 = paper, 0.5 = each style's tuned balance, 1 = ink) + **even light** (default 0.80, `src/pipeline/light.ts`): skin tone measured in bands across the face midline (medians), only the left–right antisymmetric part is subtracted — removes a side light's shadowed half, keeps symmetric shading such as beards |
| Hair | **Mode** auto / solid / tone / texture + **density** slider. auto = each style's own hair (A/B/E solid, C patterns, D dither); solid = one mass, lone flecks merged; tone = 4 pattern levels in coherent zones; texture = hair outline + strand lines (difference of Gaussians, specks under 3 cells dropped) + darkest shadows. Hair lightness is **measured** (median luminance of the hair pixels): light hair gets less ink at the same density (black hair unchanged) |
| Glasses | Auto-detect (accessories class ≥ 3 % of eye box) → eyes still redrawn **and** frames drawn as a 1-cell outline of the accessories region around the eyes; "glasses frames" toggle. (Changed 2026-10-11: skipping the eye redraw turned clear lenses into black "sunglasses" on the team photos.) |
| Edit model | Hand edits on a separate **edits layer** (per cell: auto / forced color k) over the regenerable base; **Bake** flattens style + edits into a frozen base; "live" off freezes the base without flattening, live on follows the style again (both undoable); a grid-size change rescales the edits (thin lines survive) |
| Tools | Pencil, eraser, flood fill, line, undo/redo, **mirror symmetry** (axis snaps to face centre), **feature stamps**, **select**: drag out a rectangle, drag inside it or use the arrow keys to move it; the cells it leaves take the most common colour on the ring just around the selection ("around", default) or paper — never plain ink; lifted pixels float (what they pass over survives) until dropped by Esc / Enter / another tool / a new selection, and one move is one undo step; flip ↔ / ↕ in place; **mirror copy** = a flipped copy on the other side of the mirror axis (one eye onto the other), floating so it can be nudged. Moved, flipped and copied cells become edits (forced colours) |
| Parts (photo styles; were "Stamps") | **Procedural, picked by name** (`src/pipeline/stamps.ts`, 2026-10-14). Built as ~15–20 candidates per feature, rendered on the six test faces at 50 × 50 and culled by eye (awkward ones out: tall / shine / big / liner / ring eyes, lips / o / pout / frown mouths, U-box / button / hook noses, octagon / big round / half-rim / bold glasses, brows that land on the pupils). Offered: **eyes** (14) pupils · dots · small · lids · lashes · dashes · happy · sleepy · soft lids · bar · winged · glance left · glance right · wink; **brows** (11) thin · bold · arched · short · raised · tapered · high arched · raised straight · raised bold · short raised · long; **mouth** (13) line · short · smile · wide smile · small smile · corners · open · grin · laugh · smirk · flat smile · big grin · w; **nose** (11) L · J · short L · short J · dot · nostrils · base · bridge · v · slash · curve; **glasses** (12, superellipse lenses with separate top / bottom roundness, cat-eye sweep, aviator drop, wayfarer flare) rounded · round · oval · square · pantos · cat-eye · aviator · wayfarer · browline · small round · narrow · tall. Photo-traced eyes / brows / mouth stay internal to the photo styles' auto. Glasses are sized from the **measured lenses** when the frames' segmentation goes all round (`measureLenses` in prep: lens box + rounded corners → auto shape round / oval / pantos / rounded / square), otherwise from the eye distance; rims stay continuous, a brow that would touch a rim moves up to three rows, else drops. **Auto**: image-driven avatar — pupils behind glasses or on small faces, lid + pupil otherwise, dashes for narrowed eyes; thin brows (bold ≥ 1.6 cells thick); grin for an open smile, smile, line; L nose except behind glasses; photo styles — traced shapes, dots on small grids, grin for open mouths. **08 Parts panel** (named Stamps before 2026-10-16): steppers plus an **option grid** per feature (tap its name or the feature in the view): the portrait rendered in the selected style with each option (worker `variants` request), cropped to the feature; auto / options / off. Saved by name (older projects' indices are mapped). **Moustache / beard**: a facial-hair cue (share of the lower face, lips excluded, clearly darker than the cheeks, measured on the work image; ≥ 0.5 counts) adds 1-cell paper gaps above and below the mouth and under the nose base, and in E stamps the mouth, so nose, moustache, mouth and beard stay separate shapes. A hand-drawn set can be added as more variants |
| Preview | Clean pixel-art preview only |
| Export | Exactly the editor's final composite (edits and lifted selection pixels included; refused while a style still lags a grid change), 1 px = 1 cell, no margin / grid / labels, every pixel opaque: PNG = **1-bit indexed** for two colours (own encoder: IHDR · PLTE · IDAT of stored deflate blocks · IEND, no tRNS), BMP (user-chosen bit depth 1 / 4 / 8 / 24; indexed depths carry the palette, depths too small for it are disabled), SVG |
| Autosave | IndexedDB, **last project only** (new photo replaces it): photo as lossless PNG + detection, settings, edits, bake; reopened on load; **11 reset** in the nav (and "forget this project" in export) asks "Reset everything?" in a dialog, then clears it and reloads with every setting at its default (the theme stays) |
| Devices | Desktop, tablet and phone; single workspace, panels collapse to bottom tabs on phones |
| Offline/PWA | Not now |

## Pipeline (per preset, in a Web Worker)

1. Import → EXIF orientation → downscale to ≤1600 px.
2. Detect landmarks (478 pts) + segmentation (bg / hair / body-skin / face-skin / clothes / accessories).
3. Frame crop → work image at 10× grid resolution → grayscale, bilateral smooth, CLAHE.
4. Region maps at grid res; background → chosen background.
5. Preset render:
   - **A Clean avatar** (`src/pipeline/clean.ts`): no rendering from the photo — the parts chosen (above) composed from the library at the largest art size that fits the grid, bottom centre.
   - **B Image-driven avatar** (`src/pipeline/avatar.ts`, modelled on the team's hand-finished 50×50 portraits): regions from the work image by coverage (hair takes a cell from 40 %, so thin strands survive; body "skin" under the chin far darker than the cheeks' plain grey counts as clothes), hair spurs / notches against the background smoothed, specks dropped; **face and neck stay paper** with a thin 4-neighbour contour + jaw line. **Hair = locks**: solid with one-cell paper lines on the photo's bright ridges between curls (narrow − 0.9-cell blur, `Prepared.ridge`), a line cell must be the brightest within two cells along its row or column (lines ≥ 3 apart, locks ≥ 2 wide), thinned, strands shorter than W/14 dropped, the hair's outline kept ink; light / curly hair (median luminance ≥ 95) gets many lines, dark hair a few highlights; solid dark hair on solid clothes gets a one-cell paper gap along its locks. Clothes solid. **Symmetric base**: features are drawn on the face made upright and symmetric (`symmetricFace`: eye line levelled, mirror pairs averaged about a half-cell axis, iris rings evened), and every feature except one-sided designs (wink, glances, smirk, L / J / slash / curve noses) is mirrored left half → right, so eyes, brows, mouth, glasses, moustache and goatee are exactly symmetric; on small grids eyes (with brows) and mouth are drawn larger, until the eyes are 5 cells wide (≤ 1.35×). Auto: **almond** eyes (crease, lid row corner to corner, corners + pupil) without glasses, pupils behind glasses or on tiny faces, dashes for narrowed eyes; bold brows where the real brow is ≥ 1.6 cells thick, thin above glasses, none otherwise (the crease stands in); grin for an open smile, smile, line; a short nose base (none behind glasses); glasses shaped and sized like the measured frames. **Moustache / goatee** need the lower-face cue ≥ 0.5 (bearded 0.59–0.67 at every size, others ≤ 0.46) and then their zone (≥ 0.6 / ≥ 0.3): a two-row bar (the mouth itself when closed) and a small tapered patch one paper row under the lip. Skin density above 0.50 adds shading; hand-picked stamps replace the avatar's own shapes.
   - **B Region poster**: per-region percentile thresholds (skin from slider, hair from hair controls, clothes ~p55), orphan cleanup, silhouette outline.
   - **C Line portrait**: as B but skin left open + jaw line from landmarks.
   - **D 4-tone patterns**: region-normalized tone → 4 levels → 3×3 mode filter → fixed 2×2 patterns (0/25/50/100%).
   - **E Atkinson tonal**: region-normalized tone → Atkinson dither.
   - **F ML lines**: Informative Drawings `opensketch_style` (ONNX) at input ≈ 7 × grid width, clamped 256–768 → ink coverage → grid; hair/clothes by region.
6. Feature layer (B–F): clear eye sockets + draw lid line and iris, brows, mouth, nostrils — unless glasses detected or toggle off.
7. Composite: base → edits layer → display palette.

Known weak spots (tune with `TestPortraits/`): open-smile mouths, beards under E, voluminous curly/light hair, 3/4 views.

## Architecture

- **Vite + TypeScript**, no UI framework; hand-written canvas editor.
- Processing in **Web Workers**: one for the instant styles (A–E), a second one for ML lines (F) so a model run never blocks the sliders. ONNX Runtime Web for the line model: WebGPU build when the browser has WebGPU (~0.3 s per run on an M2 Pro), otherwise the smaller CPU build (~5.5 s single-threaded; Pages isn't cross-origin isolated, so no WASM threads). The line map is cached per crop + grid, so region / line-weight sliders don't re-run the model; `@mediapipe/tasks-vision` WASM runs once per photo on the main thread with the **CPU** delegate (the GPU delegate took ~14 s on the first photo on an M2 Pro; CPU ~0.4 s).
- **All models in the repo** under `public/models/`: face_landmarker (3.7 MB), selfie_multiclass (16 MB), Informative Drawings `opensketch_style` (17 MB fp32 / ~9 MB fp16), taken from the author's own release, not the `lllyasviel/Annotators` mirror.
- Project data: `{version, source photo (downscaled), crop, grid{w,h,cellAspect}, palette[], preset{id, params}, edits: Uint8Array (0=auto, k+1=forced color k), baked}`.
- GitHub Actions builds and deploys to Pages; Vite `base: '/KnittingPixelArtEditor/'`; personal account → `<user>.github.io/KnittingPixelArtEditor`.
- License: **MIT** for code; `MODELS.md` lists each model's own license. Informative Drawings weights verified 2026-10-10: MIT (Caroline Chan), ship its MIT notice next to the ONNX file.
- `TestPortraits/` and `research/private_*` are git-ignored.
